## ブリーフとの差異・仮定

- `at` はミリ秒付き ISO 8601・+09:00。同一ミリ秒の連打や端末時計の巻き戻りでは、前回より1ミリ秒後にして押下順を区別する。
- デモは固定の generated に左右されず、端末の状態を保持する。本番とは表示用の記録を分離し、本番の未送信キューも送信しない。
- 本番の generated が空・不正なら端末の状態を残す。送信済みでも表示用の記録は generated が追いつくまで保持する。
- 未送信イベントに記録時の survey の道筋を付ける。設定変更で異なるフォルダへ送らないよう、道筋が異なる間は再送を停止し理由を表示する。
- 端末保存に失敗した押下は変更を取り消し、送信しない。通信応答が失われた場合は id・read_status・at が一致する既存イベントを確認してから送信済みにする。
