## ブリーフとの差異・仮定

- デモは1つの12ページ PDF を複数の架空論文で共有。見つからない PDF のデモは、意図的に存在しないファイル名を指定。
- 名前が空の PDF は、drive_id があってもブリーフの「PDF なし」の定義を優先。
- リダイレクトの state は10分間・一度限りで有効。成功・不一致・エラーのどの場合も該当フラグメントを URL から消す。
- 読んだページは同じ保存キー内でデモ用 ID に `demo:` を付け、本番のページ記録と衝突させない。
- 大きい PDF は表示倍率を維持しつつ canvas ごとに約400万画素・一辺8192以内へ解像度を制限し、iPhone のメモリ消費を抑える。高倍率の見え方は実機確認が必要。
- ポップアップ再ログイン時は、新しいトークンで表示中の PDF を再取得する。成功までは既存の描画を残す。リダイレクトから戻った場合は一覧に戻り、再度開くと保存ページを復元する。
