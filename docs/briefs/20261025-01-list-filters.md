# ブリーフ: 一覧の絞り込み（タグと未読／読了）

> 種別: 機能追加。Claude が作成し Codex に渡す実装仕様。

- **プロジェクト**: `/Users/kakeru/Dev/4_アプリ/PaperReader`
- **出典**: 本人 2026-10-24「論文フィルター。タグと未読／読了、この 2 種類あればとりあえずいい。もちろん検索機能は残したままで」
- **委任設定**: effort=`medium` / model=既定

## 目的

121 本（毎日増える）の一覧から、読みたいものをタグと読んだかどうかで素早く絞れるようにする。

## 作るもの（WHAT）

一覧の上（今の検索欄のまわり）に 2 つの絞り込みを足す。今の文字の検索（題・和題・タグ）はそのまま残し、**3 つはすべて同時に効く（かつ）**。

1. **読んだかどうか**: 「すべて／未読／読了」の 3 つから 1 つを選ぶ切り替え（既定は「すべて」）。判定には表示に使っている Read Status（読了ボタンで端末が上書きしている値を含む）を使う。「読了」は Read Status が「未読」以外のすべて（今の DB の「読了」、デモの「既読」など）
2. **タグ**: papers.json に出てくるタグを、論文の数が多い順に「タグ名 数」のチップで並べる。タップで選択／解除。**複数選べて、選んだタグを全部持つ論文だけ**を残す。チップの列は 1 行の横スクロールにする（横持ちは画面の高さが 390px しかないので、縦に場所を取らない）。選んだチップは見た目で分かる
- 何かが絞り込まれているときは「絞り込みを解除」のボタンを出し、押すと 3 つとも初期状態に戻る
- 件数の表示（今の「n 本 / 全 m 本」）は、3 つを合わせた結果の数にする
- 選んだ絞り込み（読んだかどうか・タグ）は端末に覚え、次に開いたときも同じにする（文字の検索は覚えなくてよい）。覚えていたタグが papers.json から消えていたら、そのタグは外す
- 読了ボタンで状態が変わったら、絞り込み中の一覧にもすぐ反映される（例: 「未読」で絞っているとき、読了にして一覧に戻ると、その論文は出ない）
- 横持ち 844×390・縦持ち 390×844 の両方で、絞り込みを足しても一覧の論文が少なくとも 1 行分は見える。390px で横スクロールが出ない（タグの列の中だけは横スクロールしてよい）

## 不可侵（壊してはいけないもの）

- 今の文字の検索と、一覧の並び（未読が先・★ の多い順）
- 読了ボタン・送り直し・端末での上書き表示（`docs/briefs/20261024-02-read-button.md`）
- 段階1の受け入れ条件（読む画面・PDF・要約・基本情報）
- `localStorage` のキー `paper-reader-v1` の名前と、今の保存内容（足すだけ）
- `fetch` は普通の関数として呼ぶ（`this.fetcher(...)` にしない）

## 制約

- 依存: 追加なし
- 入力欄の文字は 16px 以上のまま（iOS の自動拡大を防ぐ）。押すところは高さ 44px 以上（チップは高さ 36px 以上でよい）
- Service Worker を変えたらキャッシュ名を上げる（今 `paper-reader-shell-v3`）
- 範囲外: 年・会場・Importance での絞り込み／並び順の切り替え／タグの「どれか」（または）の切り替え／検索の対象を増やすこと

## 受け入れ条件（これが観測できたら完了）

- [ ] デモで「未読」を選ぶと未読だけ、「読了」を選ぶと未読以外だけが残り、件数の表示が合う
- [ ] デモでタグを 1 つ選ぶとそのタグを持つ論文だけ、2 つ選ぶと両方を持つ論文だけが残る。チップに論文の数が出て、多い順に並ぶ
- [ ] 文字の検索・読んだかどうか・タグを同時に使うと、3 つすべてを満たす論文だけが残る
- [ ] 「絞り込みを解除」で全件に戻る。何も絞っていないときはこのボタンが出ない
- [ ] 読んだかどうかとタグの選択が、再読み込みしても残る
- [ ] 「未読」で絞った状態で論文を開いて読了にし、一覧に戻ると、その論文が一覧から消えている
- [ ] `node --test tests/` が通る（上の判定・並び・覚えたタグが消えたときの扱いを含む）。`git diff --check` が通る

## エッジ / 落とし穴

- 絞り込んで 0 本になったら「該当する論文はありません。」と「絞り込みを解除」を出す
- タグの名前に記号や空白が入っていても選べる（文字は `textContent` で入れる）
- 一覧の再読み込み（papers.json の取り直し）でタグの数が変わったら、チップも作り直す
